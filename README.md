A collection of Roblox auto-farming and leveling scripts written in Luau — general game automation built for fun.

This was my very first GitHub repository. It started with collecting and tinkering with Roblox scripts — some copied, some modified, a few written by me. Going through those scripts was what first introduced me to GitHub, and slowly that curiosity about how the code actually worked turned into a genuine interest in programming and computer science.

---

## What's in here

- Auto-farming scripts
- Auto-leveling automation
- General Roblox game scripts written in Luau

---

## How to use

Load scripts via a Roblox executor of your choice.

> ⚠️ Use at your own risk. These scripts can get your Roblox account banned.
> Provided as-is with no guarantees.
